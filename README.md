# Ship & Air Watch

**Status: 0.1.0 RC2 — public preview, not production-ready.**

Raspberry Pi/Linux: receiver installation release candidate. Windows/macOS: web console and OTA tools only; native SDR installation not yet validated. Phones/tablets: browser clients, not receiver hosts.

See `docs/RELEASE-README.md` for platform limitations, setup, SHA256 manifest, and installation guidance.

## Security
Do not commit your camera, SDR service, email, SSH, or OTA credentials. Do not expose receiver administration endpoints to the public Internet without authentication.

## Licence
A project-wide open-source licence has not yet been selected. Public visibility does not grant reuse rights. Included third-party components and artwork may have separate licences.

## Status
This repository is a release-candidate snapshot. Issues and contributions can follow after the licensing and installer review.
